# Ping Pong Practice Machine: 3D layout

Interactive Three.js model of the ECE 445L ping-pong practice machine project. Drag to orbit, right-drag or shift-drag to pan, wheel to zoom. Click a part to see its owner and open items.

Illustrative layout, not to scale. Nothing here is built or tested yet.

Uses Three.js r128 from cdnjs. No build step; the whole app is `index.html`.
